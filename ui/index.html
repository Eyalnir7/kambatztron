How the Matrix Works

By default, the optimization engine will mathematically FORBID a single cadet from performing two jobs at the same time. Multiple jobs can exist at the exact same time, but they must be assigned to different cadets.

You only need to use this matrix to explicitly ALLOW exceptions to this rule (e.g. allowing 'dynamic guarding' to overlap with 'jobs at the base' for the same cadet).

System Wildcard: The engine is hardcoded to allow 'jobs at the base' and 'dynamic guarding' (cafcaf) to be consecutive with ANY other job type. You will not see this listed in the active matrix below, but it applies universally under the hood!
